# ⚔️ 파티업 (Party Up)

팀원들의 **생년월일만으로** 우리 팀을 RPG 원정대로 진단하는 팀빌딩 서비스.
사주 오행을 게임 문법(클래스 · 스탯 · 시너지 버프)으로 번역합니다.

## 기능

- 🛡️ **캐릭터 시트** — 일간(日干) 기반 클래스 10종, 오행 스탯 오각형 레이더
- ⚡ **페어 시너지** — 상생·상극·천간합 + 십성 양방향 직업 상성, MBTI 보정
- 🏕️ **파티 진단** — 팀 오행 밸런스, 파티 유형, 빈 포지션 모집 공고, 시너지 네트워크
- 🔮 **AI 도감 리포트** — Claude가 파티 전체를 읽고 쓰는 종합 전략 리포트
- 📖 **공유 카드** — 생년월일 미노출 공개 페이지 + OG 이미지

## 실행

```bash
npm install
npm run dev
```

## 환경변수 (선택)

| 변수 | 용도 |
|---|---|
| `ANTHROPIC_API_KEY` | AI 도감 리포트 활성화 (없으면 잠금 안내 표시) |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | 파티 데이터 영구 저장 (Upstash/Vercel KV). 없으면 파일(/tmp) 폴백 |

## 고지

파티업은 사주 명리를 게임 문법으로 풀어낸 **팀빌딩·재미 콘텐츠**입니다.
결과는 과학적 근거가 있는 평가가 아니며, 채용·인사평가 등 사람에 대한 판단에 사용해서는 안 됩니다.
